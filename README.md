# Akıllı Hesap Makinesi

Python ve Tkinter kullanılarak geliştirilmiş, grafik arayüze sahip bir hesap makinesi.

## Özellikler

* Toplama, çıkarma, çarpma ve bölme işlemleri
* İşlem önceliği ve parantez desteği
* Üs alma ve mod alma
* İşlem geçmişini görüntüleme
* Klavyeden işlem yapabilme
* Koyu temalı grafik arayüz
* Hatalı işlemler için hata mesajları

## Kullanılan Teknolojiler

* Python 3
* Tkinter
* AST (Abstract Syntax Tree)

## Gereksinimler

Python 3 kurulu bir bilgisayar.

Tkinter, standart Python kurulumlarında genellikle hazır gelir.

## Nasıl Çalıştırılır?

1. Bu depodaki `hesap_makinesi.py` dosyasını bilgisayarına indir.
2. Python kurulu olduğundan emin ol.
3. Dosyayı Python IDLE ile aç.
4. `F5` tuşuna basarak programı çalıştır.

## Kullanım

* Sayıları ve işlem işaretlerini butonlardan veya klavyeden gir.
* `=` butonuna veya `Enter` tuşuna basarak sonucu hesapla.
* `Temizle` ile ekranı temizle.
* `Sil` ile son karakteri sil.
* `Geçmiş` ile önceki hesaplamaları görüntüle.
* `Yeni İşlem` ile yeni bir hesaplamaya başla.
